# Code of Conduct

## Humara vaada

SatarkPay ek **public-good** project hai — fraud victims ke liye. Isliye contributors se expect karte hain:

- **Fraud victims ke saath samman.** Koi blame nahi ("aapne hi OTP diya"), koi shaming nahi, koi "kitna paisa gaya" ka mazak nahi.
- **No stock tips / no promotion.** Ye repo SEBI-compliance ke dayre me hai: koi buy/sell/hold, price target, paid-group promotion, ya broker referral yahan allowed nahi.
- **Privacy pehle.** Real evidence (kisi ki screenshots, UPI ids, phone numbers) bina likhit permission commit mat karo. Synthetic ya masked data hi use karo.
- **Honest claims.** Naye numbers/benchmarks add karne se pehle batana ki wo kaise measure hue. "93% accurate" jaise claims ke saath set, size aur limit likhna zaroori hai.
- **Bharat-first.** Copy Hinglish/Hindi me pehle likho, aur native review maango.

## Kya nahi chalega

Harassment, casteist/communal/sexist language, doxxing, scam-tooling code, ya kisi ko victim-blame karna. Aisa kuch hua to maintainers warning dekar ya bina warning remove/ban kar diye jayenge.

## Report kaise karein

Maintainers ko email karo (repo ke SECURITY.md me address hai) ya issue kholo `[conduct]` tag ke saath. Sab reports 7 din me dekhi jayengi, aur reporter ki identity private rahegi.
