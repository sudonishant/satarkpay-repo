# 3-minute demo script (judges ke saamne)

**Setup:** `web/satarkpay_m2.html` browser me kholo (fullscreen, `speed ×30` OFF rakho jab tak neeche na likha ho).
**Golden rule:** har beat me ek hi baat — *“paisa bhejne se pehle 60 second, aur fraud ke baad 60 minute.”*

---

## 0:00–0:20 · Hook (bolne ke liye)

> “Scam ab padhne ka nahi, *hone* ka hai. Aaj 77% competitor solutions ek hi kaam karte hain — aap message paste karo, woh score dete hain. Yaani fraud **ho jaane ke baad**. Hum payment se **pehle** rukte hain, aur agar fraud ho gaya to **3 minute me complaint** taiyaar kar dete hain.”

## 0:20–1:10 · M1 · Chat-Before-Pay (tab `01`)

1. Chip **“Saved + 2 min chat”** → `01:00` fast path dikhao → bolo: *“saved contact, 1 minute check ya ek tap me call-confirm — friction minimum.”*
2. Chip **“Saved + 12 min chat”** → notification card dikhao → *“number saved hone par bhi — 10 minute baat ke turant baad payment = coercion ka pattern.”*
3. Chip **“Unknown + lambi chat”** → T3 hold + analyst callback → *“yahi digital-arrest aur task-scam ka shape hai.”*
4. `speed ×30` **ON** karo → clock 9 minute ko 18 second me dikhao (bolo: “real device par asli 9 minute — demo me compress kiya hai”).
5. **Zor dein:** “Koi auto-block nahi — payment rukta hai, final call user ki.”

## 1:10–1:50 · M2/M3 · Screenshot + domain (tab `02`, `03`)

6. Tab `02`: 3 screenshots ke burst par amber → red; “agla payment simulate karo” dabao → 3rd payment par **cooling (R22)**, 4th par **hold**.
7. Tab `03`: domain ladder L1→L4; phir **gateway merhant mismatch** card → *“gateway achha ≠ merchant achha — ye 2026 ki sabse badi trick hai.”*

## 1:50–2:30 · M4 · Sanchalak + eval (tab `04`)

8. Chip **“SEBI-registered tip (fake number)”** → verdict + **R26 registry flag** (“SEBI12345 format me hi nahi hai”) → *“hum ‘registered hai’ certify nahi karte — format, domain aur list check karte hain.”*
9. Chip **“bank ka OTP warning (negation)”** → **SEEMS OK** → *“bank ka apna safety alert scam nahi ginte.”*
10. **`▶ Run eval (33 messages)`** dabao → live **P 95% · R 90% · F1 93%**, aur table me `miss`/`false-alarm` tags dikhao → *“ye set humne khud likha hai — ceiling hai, field accuracy nahi. Isliye ‘PAKA NAHI BATA SAKTA’ bhi ek valid jawab hai.”*
11. `🔊 voice: हिंदी ON` + `👁 senior: ON` — ek verdict sunao/dikhao (accessibility 10 second).

## 2:30–3:00 · M7 + R38 · Fraud ke baad (tab `07`)

12. `📦 1930 / NCRP pack banao` → annexure + hashes (chain of custody).
13. **`🚨 Fraud CONFIRM hai`** dabao → 3 steps: **email** (cyber cell 3 IDs + bank cc), **call** (1930 script), **payment stop** (dispute + CFCFRMS + mandate revoke) → clock chalta hua dikhao.
14. Close: *“Golden hour me hum sirf advice nahi dete — complaint, call aur freeze request ek screen par ready kar dete hain. Yehi hamara asli differentiator hai.”*

## Judge ke sawal (ready jawab)

| Sawal | Jawab (30 sec) |
|---|---|
| “Ye Android permissions ke bina kaam karega?” | Manual mode: paste-and-check + dropdown dwell + user-driven evidence. Banner me likha hota hai kya off hai. |
| “97% accuracy claim?” | Hum 95/90/93 bolte hain aur saath me likhte hain: self-authored set = ceiling, sach ka pata field se chalega. Miss/FP table me dikhte hain. |
| “LLM hallucination?” | Verdict deterministic engine se; LLM sirf explanation. Prompt-injection ke liye user text untrusted hai, tool-calling nahi. |
| “Paisa wapas milega?” | Guarantee nahi de sakte. Hum pehla 60 minute optimise karte hain — 1930 + bank freeze + NCRP, kyunki freeze-trace ka mauka wahi hota hai. |
| “Peer repos se copy?” | 30/31 par license hi nahi (all rights reserved) → zero code copy, sirf ideas + credit `NOTICE.md` me. |
| “Scale kaise?” | On-device pehle → PSP/telecom/exchange hooks (UPI Help, Sanchar Saathi, SCORES) → registry OTA se naye patterns bina app update. |
